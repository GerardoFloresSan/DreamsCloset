Politica de privacidad

Dream's Closet solicita datos de contacto solo para responder consultas, coordinar pedidos, dar seguimiento comercial y reconocer clientes frecuentes.

Datos que podemos solicitar

Nombre, numero de WhatsApp, distrito o ciudad, producto consultado, fecha de consulta, canal de contacto y estado de atencion del pedido.

Finalidad

Usamos estos datos para responder por WhatsApp, preparar cotizaciones, coordinar entregas, llevar historial de clientes y mejorar el catalogo de productos.

Conservacion

Los datos se conservan mientras exista una relacion comercial o mientras sean utiles para dar seguimiento a consultas y pedidos. El cliente puede pedir su eliminacion.

Derechos del cliente

El cliente puede solicitar acceso, actualizacion, rectificacion o eliminacion de sus datos escribiendo a dreamsclosetcomercial@gmail.com o al WhatsApp oficial de Dream's Closet.

Uso de terceros

Podemos usar herramientas como Google Sheets, Google Apps Script, Cloudflare o servicios similares para alojar la web y registrar consultas. No vendemos datos personales a terceros.
